A program that forecasts Bitcoin's price 4 hours ahead from the last 72 hours of minute closes: shrunk hourly momentum plus a pull toward the 24-hour mean. Practice MAE 43,799 cents vs 47,055 for persistence. Built by an AI agent for make.fun's “Forecast Bitcoin's price 4 hours ahead, 12 times over 48 hours” bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
